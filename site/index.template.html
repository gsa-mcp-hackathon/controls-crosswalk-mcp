Controls Crosswalk MCP

Source-cited answers about federal security controls, for AI agents. One read-only MCP server over NIST SP 800-53, the SP 800-53B baselines, the Cybersecurity Framework 2.0, and the FedRAMP Key Security Indicators.

  • View the code on GitHub
  • Read the evaluation

Built for the 2026 GSA MCP Server Hackathon. Unofficial: not affiliated with or endorsed by NIST, GSA, or FedRAMP.

The challenge

Security teams keep answering the same questions by hand:

  • What changed between SP 800-53 release 5.1.1 and 5.2.0?
  • Which baselines select this control?
  • Which controls does FedRAMP relate to this Key Security Indicator?
  • How does CSF 2.0 point to SP 800-53?

The answers are spread across four publications from NIST and FedRAMP, each in its own format. A wrong control count or an invented mapping in an authorization package is worse than no answer.

{{base_correct}} of {{total}} gold questions a current AI model answered correctly without the server.

  • It said 12 controls were added in release 5.2.0. The answer is 3.
  • It answered KSI-CNA-01 where the answer is KSI-PIY-RES.
  • It repeated a false claim that AC-2 was withdrawn.

The solution

One server holds all four sources in a single pinned snapshot and exposes nine read-only tools over the Model Context Protocol.

One pinned, hashed snapshotSQLite store, opened read-only

AI agent or assistant

  • Every answer cites its source

    Each result carries the snapshot hash, the source file, and a citation URL.

  • Published links are labeled

    Direct means one published link. Derived means the server composed links, and it shows the path.

  • No compliance verdicts

    The server never states that a requirement, control, or indicator is satisfied.

Nine tools built around user goals

Each tool is an action a person asks for. Identifiers work in any common spelling, such as AC-2(3), AC-02(03), or ac-2.3.

  • controls_get_control

    One control in full, in either release.

  • controls_search

    Full-text search with family, baseline, and release filters.

  • controls_diff_releases

    What changed between two releases, with before and after text.

  • controls_get_baseline

    The members of one SP 800-53B baseline.

  • controls_baseline_membership

    Which baselines select each of up to 50 controls.

  • controls_get_csf_element

    A CSF 2.0 function, category, or subcategory with its references.

  • controls_get_ksi

    FedRAMP KSI themes and indicators with their related controls.

  • controls_crosswalk

    Follow published links between a control, a CSF element, and a KSI.

  • controls_data_status

    Which datasets the server holds, the snapshot hash, and every source.

See it work

Three examples. The first and third show real tool output from the pinned snapshot. The second is a recorded run from the evaluation.

Example 1 What changed in a control

What changed in SI-7(12) between SP 800-53 release 5.1.1 and 5.2.0?

One tool call: controls_diff_releases(control_id="SI-7(12)")

Release 5.1.1Require that the integrity of the following user-installed software be verified prior to execution: [Assignment: organization-defined user-installed software].

Release 5.2.0Require that the integrity of the following software be verified prior to execution: [Assignment: organization-defined software].

Release 5.2.0 removes the "user-installed" restriction. The organization still specifies which software requires integrity verification. The same call also returns the changes to the discussion, the parameter, the assessment objective, and the test method.

Example 2 A question that needs many steps

Exactly one FedRAMP Key Security Indicator lists no related SP 800-53 controls. Which one?

  • KSI-PIY-RES the agent's answer, correct, in 5.0 seconds

  • 11 tool calls, the same in all five repeated runs

  • KSI-CNA-01 the same model's wrong answer without the server

Example 3 Following published links

Which FedRAMP Key Security Indicators connect to CSF subcategory PR.AA-01?

One tool call: controls_crosswalk(source_id="PR.AA-01", to_framework="ksi")

  1. PR.AA-01CSF 2.0 subcategory
  2. IASP 800-53 family
  3. IA-12SP 800-53 control
  4. KSI-IAM-AAMFedRAMP indicator

The tool reports no direct links and seven derived indicators. In this path NIST published the first link as an informative reference, the second is family membership from the catalog, and FedRAMP published the third as a related control. The server composed the chain and labels it derived: a starting point for analysis, not a published mapping.

How to read these numbers

The runs compare configurations, and the prompts differ. The full prompt gives two source-specific hints and tells the agent to check claims with the tools. The no-tools prompt does not, so that gap is not the tools alone. The basic prompt has no hints and no scope or injection rules. Security

  • Public data only

    Every source is public. No PII, CUI, or agency system data is in the store, the questions, or the traces.

  • Read-only by construction

    No write tools. The store is opened read-only. The server makes no network calls while answering.

  • No credentials

    The server needs none. The evaluation key stays in an uncommitted file and is not passed to the server process.

  • Scope containment

    The server never says a control is satisfied, and a scope judge checks that the agent does not either.

  • Prompt injection tested

    Three gold questions are injection attempts. The agent treats instructions inside a question as data.

  • Pinned, hashed sources

    A changed upstream file changes the snapshot hash that every answer reports.

The HTTP transport has no authentication. It is meant for a sandbox or a platform that puts its own access control in front of it.

Limits

  • The CSF references come from NIST's CPRT export, which gives them at the family level. NIST publishes control-level mappings in a separate reference catalog that this server does not hold.
  • The gold set has {{total}} questions, written by the one developer who built the server. No gold question exercises the crosswalk tool.
  • Results describe one agent model and one judge model on one snapshot.
  • The content has not yet been reviewed by an Information System Security Officer or an assessor.

Run it

You need uv. The server runs locally over stdio. The README has the client configuration.

uv sync --group dev
uv run python -m crosswalk_mcp.snapshot fetch
uv run python -m crosswalk_mcp.store build
uv run crosswalk-mcp
